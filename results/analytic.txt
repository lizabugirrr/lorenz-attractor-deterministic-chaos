=== C± ===
char poly: 2*beta*r*sigma - 2*beta*sigma + lambda**3 + lambda**2*(beta + sigma + 1) + lambda*(beta*r + beta*sigma)
a2 = beta + sigma + 1 ; a1 = beta*(r + sigma) ; a0 = 2*beta*sigma*(r - 1)
Routh–Hurwitz a2*a1 - a0 = beta*(beta*r + beta*sigma - r*sigma + r + sigma**2 + 3*sigma)
r_H = -sigma*(beta + sigma + 3)/(beta - sigma + 1) = 470/19 ≈ 24.736842

=== Глобальна стійкість при r<1: V = x^2/sigma + y^2 + z^2 ===
dV/dt = -2*(beta*z**2 - r*x*y + x**2 - x*y + y**2)
dV/dt - target = 0 (0 => тотожність доведена)

=== Поглинаюча множина: V = r x^2 + sigma y^2 + sigma (z-2r)^2 ===
dV/dt = -2*sigma*(-2*beta*r*z + beta*z**2 + r*x**2 + y**2)
dV/dt - target = 0

=== Пекора–Керролл: синхронізація (y,z)-підсистеми ===
d/dt (e_y^2+e_z^2)/2 = -beta*e_z**2 - e_y**2
